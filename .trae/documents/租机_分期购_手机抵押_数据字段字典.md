# 数据字段字典（MVP）

> 说明：本字典聚焦MVP必需字段；扩展字段建议以 JSONB 放入 payload/metadata 便于快速迭代。

## 1) profiles（用户扩展档案）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | uuid | 是 | 对应 Supabase Auth 用户ID |
| phone | string | 是 | 用户手机号 |
| full_name | string | 否 | 姓名 |
| id_number | string | 否 | 证件号 |
| kyc_status | enum | 是 | unverified/pending/verified/rejected |
| created_at | datetime | 是 | 创建时间 |

## 2) applications（申请单）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 申请单ID |
| user_id | uuid | 是 | 申请人 |
| biz_type | enum | 是 | lease/installment/pledge |
| payload_json | jsonb | 是 | 申请表数据（差异字段放这里） |
| status | enum | 是 | draft/submitted/under_review/need_more_info/rejected/approved/canceled |
| submitted_at | datetime | 否 | 提交时间 |

## 3) orders（订单/合同主表）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 订单ID |
| application_id | uuid | 是 | 来源申请单 |
| user_id | uuid | 是 | 归属用户 |
| biz_type | enum | 是 | lease/installment/pledge |
| status | enum | 是 | 见《状态机》 |
| principal | number | 否 | 本金（分期/抵押） |
| deposit | number | 否 | 押金（租机可用） |
| down_payment | number | 否 | 首付（分期可用） |
| term_months | int | 否 | 期数（分期/租机） |
| apr | number | 否 | 年化利率/服务费口径（抵押/分期可用） |
| pricing_snapshot | jsonb | 是 | 报价快照（必存） |
| contract_signed_at | datetime | 否 | 签署时间 |
| closed_reason | string | 否 | 关闭原因（拒绝/取消/违约） |

## 4) device_assets（设备/抵押物信息）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 设备ID |
| imei | string | 是 | IMEI/序列号（至少其一） |
| model | string | 否 | 型号 |
| ownership | enum | 否 | platform/user/partner |
| lock_status | enum | 否 | normal/icloud_locked/frp_locked/unknown |
| condition_grade | enum | 否 | A/B/C/unknown |
| metadata | jsonb | 否 | 机况说明、图片链接等 |

## 5) risk_reviews（审核/风控结论）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 审核ID |
| order_id | uuid | 是 | 对应订单 |
| decision | enum | 是 | approved/rejected/need_more_info |
| reason_codes | string[] | 否 | 原因码数组（如 ID_MISMATCH、IMEI_DUP） |
| hit_rules | jsonb | 否 | 命中规则明细（规则名/阈值/结果） |
| reviewer_id | uuid | 是 | 审核人 |
| decided_at | datetime | 是 | 审核时间 |

## 6) repayment_schedules（还款计划）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 计划ID |
| order_id | uuid | 是 | 订单ID |
| period_no | int | 是 | 期次（从1开始） |
| due_date | date | 是 | 到期日 |
| amount_due | number | 是 | 应还金额 |
| amount_paid | number | 是 | 已还金额 |
| status | enum | 是 | unpaid/partial/paid/overdue |

## 7) payments（支付/入账记录）
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | uuid | 是 | 支付ID |
| order_id | uuid | 是 | 订单ID |
| pay_type | enum | 是 | deposit/down_payment/repayment/disbursement |
| amount | number | 是 | 金额（放款可为负或单独字段） |
| status | enum | 是 | initiated/succeeded/failed/manual_recorded |
| channel | string | 否 | 渠道（如线下/转账/第三方） |
| paid_at | datetime | 否 | 成功时间 |

## 8) 关键枚举（建议）
- biz_type：lease/installment/pledge
- 原因码（示例）：ID_MISMATCH、DOC_FAKE_SUSPECT、MULTI_APPLY_FREQUENT、CONTACT_DUPLICATE、IMEI_DUPLICATE、DEVICE_LOCKED、PAYMENT_RETRY_EXCEEDED
