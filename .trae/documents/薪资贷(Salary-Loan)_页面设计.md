# 薪资贷（Salary/Payroll Loan）页面设计（Desktop-first）

## 全局规范（适用于所有页面）
- Layout：桌面端以 12 栅格 CSS Grid 为主，表单/列表区域采用 Grid + Flex 混合；内容最大宽度 1200px，居中；重要操作区固定在右侧或底部悬浮。
- Breakpoints：Desktop（≥1200）完整双栏；Tablet（768–1199）改为单栏；Mobile（≤767）表单分步折叠。
- Global Styles（设计令牌建议）
  - 背景：#F7F8FA；卡片：#FFFFFF；主色：#1E6FFF；警示：#FF4D4F；成功：#22C55E；文字：#111827/#6B7280
  - 字体：标题 20/18/16；正文 14；辅助 12；数字金额使用等宽字体（可选）
  - 按钮：Primary/Secondary/Danger；hover 加深 6%；disabled 降低透明度
  - 表单：必填 * 标识；错误提示行内展示；上传组件支持拖拽
- 交互：所有关键动作二次确认（签约、放款、减免、核销）；所有后台操作写入操作日志（可在UI中查看）。

## 1) 借款人登录/注册页（/login）
- Meta
  - title：薪资贷登录
  - description：使用手机号快速登录并申请薪资贷
  - OG：title/description 同步
- Page Structure：居中单卡片布局
- Sections & Components
  1. 顶部品牌区：Logo + 产品一句话说明
  2. 登录卡片
     - 手机号输入（含国家码下拉）
     - OTP发送按钮（含倒计时、频控提示）
     - OTP输入
     - 条款勾选区（4项）：《服务协议》《隐私政策》《数据授权》《催收告知》（均可点击弹窗全文）
     - 主按钮：登录/继续
  3. 页脚：客服联系方式/工作时间（MVP可仅文本）

---

## 2) 借款人申请首页（/apply）
- Meta
  - title：申请薪资贷
  - description：填写资料、完成验证与签约
- Page Structure：左侧步骤条 + 右侧表单卡片（Desktop双栏）
- Sections & Components
  1. 顶部导航：当前状态Badge（待验证/审核中/已放款等）+ “我的订单”入口
  2. 左侧步骤条（Steps）
     - KYC资料 → 就业信息 → 工资证明 → 费用与还款日确认 → 提交
  3. 右侧表单区（按步骤分屏）
     - KYC：证件号、证件照片上传、自拍/人脸结果展示（MVP可上传+人工）
     - 就业：工厂选择（搜索/下拉）、工号、入职日期、部门
     - 工资：最近N次发薪金额与日期（表格可增删行）、工资单/截图上传
     - 费用与还款：额度试算组件（输入期数/金额后展示“本金/利息/费用/总应还/APR提示”）
     - 授权弹窗：逐项授权开关（按最小必要）+ 说明
  4. 底部粘性操作条：上一步/下一步/提交申请
  5. 提交后状态面板：展示“待工厂验证”与预计时效；提供补充资料入口

## 3) 订单详情/还款页（/order/:id）
- Meta
  - title：订单详情与还款
  - description：查看合同摘要与还款计划
- Page Structure：上方摘要卡 + 下方左右两列（计划/凭证）
- Sections & Components
  1. 订单摘要卡：订单号、状态、放款日、到期日、应还总额、逾期天数（如有）
  2. 还款计划表：期数、应还、已还、状态；逾期行高亮
  3. 还款方式卡片（MVP）
     - 转账信息/收款账号
     - “我已还款”上传凭证（图片/文件）+ 备注
  4. 合同与条款：只读链接 + 下载

## 4) 后台登录页（/admin/login）
- Meta：title=后台登录
- Layout：居中卡片；与借款人登录区分色调（灰蓝）
- Components：账号、密码、验证码（可选）、登录按钮、忘记密码（MVP可隐藏）

---

## 5) 后台工厂验证与风控审核台（/admin/verify, /admin/risk）
- Meta：title=工厂验证/风控审核
- Page Structure：顶部导航 + 左侧菜单 + 主内容（表格+详情抽屉）
- Sections & Components
  1. 左侧菜单：验证队列/工厂管理/风控审核
  2. 验证队列（Table）
     - 列：申请人、工厂、工号、提交时间、验证状态、风险提示
     - 行操作：进入详情、标记“需补充”、上传验证材料
     - 详情抽屉：在职确认、发薪信息录入、HR沟通记录
  3. 风控审核台
     - 左：申请概要（KYC/就业/工资）
     - 右：评分卡片（RiskScore、原因码、规则命中）+ 决策按钮（通过/复核/拒绝）
     - 放款区（仅通过后可见）：放款金额、通道、外部回执号、确认放款（二次确认）

---

## 6) 后台订单/账本/催收工作台（/admin/ledger, /admin/collections）
- Meta：title=订单与催收
- Page Structure：Tab切换（订单/账本/催收）+ 顶部筛选条
- Sections & Components
  1. 订单Tab：筛选（状态、工厂、DPD、金额区间）+ 列表 + 订单详情
  2. 账本Tab
     - 分录时间线：按事件分组（放款/计提/回款/减免/冲正）
     - 对账标记：external_ref展示；支持“已对账/异常”
  3. 催收Tab
     - 逾期分案列表：DPD、金额、阶段、分配人、最近跟进
     - SOP提示面板：根据DPD自动展示建议动作与合规提醒
     - 跟进记录表单：联系渠道、结果、原因码、PTP（日期/金额）、下次跟进时间
