# 页面设计说明（用户端：Telegram Mini App / TMA）

## 全局设计规范（TMA）
- 信息架构：/services（入口聚合）→ /apply（申请表单）→ /applications（我的申请）→ /applications/:id（详情）；一级用底部 TabBar（自绘，≤5），二级页启用 Telegram BackButton。
- 主题：完全跟随 Telegram `themeParams`，用 CSS 变量实现颜色/背景/文本/按钮；支持 themeChanged。
- 主操作：表单“下一步/提交/确认”等关键动作优先使用 Telegram `MainButton`（随校验显示与禁用）。
- 错误与离线：顶部 ErrorBanner + OfflineBar；离线时禁用提交并允许草稿暂存。
- 权限：手机号（必需）与联系人（用于紧急联系人，可选/按需）均通过 Telegram 授权优先，失败提供手动录入兜底，并明确用途。
- 多语言与性能：默认跟随 Telegram 语言；语言包懒加载；图片压缩+懒加载，列表分页/虚拟化，避免重型动效。

---

## 1) 业务入口聚合页（/services）
- Layout：TMA 单栏纵向滚动；顶部使用 Telegram Header（标题+可选右侧帮助入口）。
- Sections & Components
  - 业务卡片列表（纵向 3 张卡片）
    - 卡片内容：业务名称、适用人群一句话、关键成本点（示例区间）、CTA。
    - 交互：点击卡片进入 /apply/:bizType；若资料未完善，先引导到 ProfileSetup。
  - 费用示例（轻量 Tabs，横向滚动）
    - 展示：示例设备价/期数/预计月供或日租；免责声明。
  - FAQ（折叠面板）
    - 仅保留 MVP：审核时长、逾期影响、提前结清说明。

## 2) 账号与授权（ProfileSetup / Me 子模块）
- Layout：TMA 单栏表单；二级页启用 BackButton。
- Components
  - 手机号授权（必需）：按钮「授权手机号」→ Telegram 授权；失败兜底为手动输入 + 校验。
  - 紧急联系人（按业务需要/可选）：按钮「从 Telegram 选择联系人」→ 授权联系人；失败兜底为手动录入（姓名/关系/电话）。
  - 条款勾选：必须同意后才允许继续；关键提交动作放在 MainButton。
  - 状态展示：已绑定手机号/已授权联系人/实名状态（若后端有）。

## 3) 申请页（/apply/:bizType，统一表单）
- Layout：TMA 单栏为主；顶部 Stepper（横向可滚动）+ 分组卡片表单；主提交动作用 MainButton。
- Sections & Components
  - Stepper：选择业务 → 填资料 → 传材料 → 确认提交（步骤间切换需保存草稿）。
  - 表单分组 Card
    - 业务信息：业务类型、设备型号/价格（租机/分期必填）、期数（分期必填）、抵押物信息（抵押必填）。
    - 身份信息：姓名、证件号、有效期；展示实名状态。
    - 联系信息：紧急联系人（优先 Telegram 授权联系人，允许手动兜底）。
    - 地址信息：收货/取机地址（按业务显示）。
    - 材料上传：图片压缩后上传；支持失败重试与断点提示。
  - 费用/关键信息摘要（贴底浮层或表单末尾卡片）
    - 展示试算：押金/首付、月供/租金示例、总成本提示；MainButton 仅在校验通过时启用。

## 4) 申请/订单详情页（/applications/:id）
- Layout：TMA 单页纵向信息流；详情页启用 BackButton；关键动作放 MainButton。
- Components
  - 状态区：状态标签 + 时间线（纵向 Step/Timeline）。
  - 信息分组 Tabs（移动端可用 SegmentedControl/横向滚动 tabs）
    - 基本信息：报价快照、期数、押金/首付、合同摘要。
    - 材料与记录：已上传材料列表；审核备注只读。
    - 还款计划：以卡片列表替代密集表格（到期日、应还、已还、状态）。
  - 动作区（随状态变化）
    - 待补件：MainButton「补充材料」。
    - 待签约：勾选同意后 MainButton「确认签署」。
    - 待支付：MainButton「去支付」或展示支付指引。

## 5) 运营/风控审核台
- Page Structure：左侧筛选 + 右侧列表；点击进入抽屉/详情页
- Components
  - 筛选区：业务类型、状态、命中标签、申请时间范围
  - 列表：申请人、业务类型、金额/设备、命中摘要、当前状态、操作
  - 审核详情（抽屉）
    - 材料预览（图片/文件）
    - 风控命中点（规则名/阈值/结果）
    - 审核结论：通过/拒绝/补件；原因码多选；备注输入
    - 操作日志：时间、操作者、动作、备注
