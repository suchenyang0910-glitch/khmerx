# 核心规则与风控点（MVP）

## 1. 统一规则（适用于三类业务）
### 1.1 申请准入与资料完整性
- 必填：手机号已验证；姓名+证件号；紧急联系人；必要材料上传（按业务类型）
- 一致性校验（MVP为规则提示+人工复核）：姓名/证件号与上传证件一致；手机号与联系人不完全相同

### 1.2 定价与快照
- 申请提交时固化“报价快照”：设备价格/折旧（租机）、期数（月供）、押金/首付、利率/服务费（抵押/分期）
- 报价变更原则：提交后不可由用户自行修改；如需调整只能由运营在审核时改并留痕

### 1.3 审核结论
| 结论 | 含义 | 对用户的结果 |
|------|------|--------------|
| 通过 | 满足准入/风险可控 | 进入待签约/待支付或待放款 |
| 补件 | 信息不足或疑点未消除 | 订单进入“待补件”，用户可补充材料 |
| 拒绝 | 命中硬性拒绝或风险过高 | 订单关闭；保留原因码用于复盘 |

## 2. 业务规则

### 2.1 租机（lease）
- 交付标的：设备（平台提供/合作商提供）
- 费用组成（MVP）：押金（可选）+ 首期租金（可选）+ 月租（按月）
- 所有权与违约：履约期间设备归属平台/合作方；逾期达到阈值可触发“锁机/回收/黑名单”（MVP只记录处置动作，不强制技术对接）

### 2.2 分期购（installment）
- 交易结构：用户购买设备，平台提供分期付款安排
- 费用组成（MVP）：首付（可选）+ 分期本金 + 服务费/利息（可选）
- 提前结清：MVP可不做复杂减免，提示“以合同为准”，但需支持将订单置为“已结清”并记录线下结清凭证

### 2.3 手机抵押（pledge）
- 抵押物：用户自有手机（需IMEI/序列号/机况）
- 放款规则（MVP）：通过审核并签约后放款；额度与抵押物估值相关（MVP可人工录入额度）
- 赎回：还清后订单结清；抵押物返还（MVP记录返还时间与签收证明）

## 3. 风控点（MVP：规则提示 + 人工审核）

### 3.1 申请欺诈
- 身份冒用：证件照片疑似PS/信息不一致（人工核验）
- 多头申请：同证件号/手机号短期多次申请（规则：24h内申请次数>阈值）
- 联系人风险：紧急联系人手机号与本人重复/过多订单关联（规则：联系人关联订单数>阈值）

### 3.2 设备风险（重点）
- IMEI/序列号重复：同IMEI绑定多订单/多用户（硬拒或升级审核）
- 锁机状态：iCloud/Google FRP 未解除（硬拒或补件）
- 机况异常：屏幕/主板维修、进水等（影响估值与额度，MVP人工判断）

### 3.3 支付与履约风险
- 首付/押金支付失败：限制反复尝试次数，超过阈值进入人工复核
- 逾期分层：
  - D1~D7：提醒+记录
  - D8~D30：升级催收+限制新申请
  - D30+：进入处置（回收/法务/黑名单）

### 3.4 审核留痕与可追溯
- 每次审核必须：结论 + 原因码 + 备注（可空但建议）+ 时间 + 审核人
- 关键参数变更必须留痕：额度、期数、押金/首付、利率/服务费、处置动作

> 对应字段与原因码建议见《租机_分期购_手机抵押_数据字段字典.md》。
